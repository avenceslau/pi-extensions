# Bro

Explain the material supplied after `/skill:bro`. If no material is supplied, explain the most relevant preceding response or topic in the conversation.

Use plain, direct language for a smart non-expert:

- Lead with the main point.
- Explain what it means and why it matters.
- Define or replace jargon.
- Include the next action only when one is relevant.
- Keep it concise unless the user asks for more detail.
- Do not use tools or take action; only explain.
